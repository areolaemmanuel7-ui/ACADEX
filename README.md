# ACADEX starter

A mobile-first static frontend prototype for ACADEX — Everything campus. One ecosystem.

## Files
- `index.html` — page structure
- `styles.css` — responsive black-and-gold styling
- `app.js` — small demo interaction and service-worker registration
- `manifest.webmanifest` — progressive web app metadata
- `sw.js` — basic offline cache
- `README.md` — project notes

## Run
Open `index.html` in a browser, or deploy this folder to a static host such as Netlify or GitHub Pages.

## Important
This is a frontend prototype only. It does not yet include real accounts, a database, messaging, payments, moderation, or live opportunity listings. Those require later engineering work. Never put private API keys, passwords, or student personal data in this public repository.
